Feat-003 | CoffeeCard Sub-Component with Milk Pills                  [done]
------------------------------------------------------------
File: hafotty-coffi/src/website/pages/coffeeType/coffeeType.jsx

CoffeeCard extracted as a named function component (not exported).
Local state: const [localMilk, setLocalMilk] = useState(basketItem?.milkChoice ?? 'Full Fat')
  — initialises from basket if item already added, otherwise defaults to Full Fat.

Milk options (5 pills):
  Full Fat | Skimmed | Oat | Soy | None

Pill behaviour:
  - Selected pill highlighted gold (.coffee-card__milk-pill--active).
  - Selecting a pill updates localMilk state.
  - If item is already in basket (qty > 0), also calls updateMilkChoice to sync.
  - + button calls addItem(coffee, localMilk) instead of addToBasket.
  - − button calls updateQuantity(coffee.id, qty - 1) as before.

CoffeeType parent component now only handles the header bar and grid layout.
It reads basketCount from useBasket for the nav badge.
