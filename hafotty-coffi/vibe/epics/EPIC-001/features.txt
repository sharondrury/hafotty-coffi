Feat-010 | Basket Context (Global State)                              [done]
------------------------------------------
Create src/website/components/basket/basketContext.jsx.
Holds basket state for the entire session — persists across all page navigation.
State shape:
  basket: array of { id, name, type, size, quantity }
Exposed via BasketProvider and useBasket() hook:
  - basket: current array of items
  - addToBasket(item): adds item or increments quantity if id already exists
  - removeFromBasket(id): removes item entirely
  - updateQuantity(id, quantity): sets quantity; removes item if quantity <= 0
  - basketCount: derived total number of individual items (sum of quantities)
BasketProvider wraps the entire app in App.jsx.
