Feat-001 | Coffee Data Array                                          [done]
------------------------------
Define a COFFEES data array inside coffeeType.jsx (above the component).
Each coffee object contains:
  {
    id: 'flat-white',           // unique slug, kebab-case
    name: 'Flat White',         // display name
    description: 'Short one-line descriptor',
    image: '/assets/images/coffeeDrink/<filename>.jpg',  // path relative to public or imported
  }
Populate with as many entries as there are images in the coffeeDrink folder.
Images should be imported at the top of coffeeType.jsx using ES module imports
(e.g. import flatWhiteImg from '../../assets/scss/images/coffeeDrink/flatWhite.jpg')
so Vite handles the asset pipeline correctly.

10 images found and used:
  caffe-mocha.png, iced-coffee.png, latte.png, iced-mocha.png, latte-macciato.png,
  cappuccino.png, americano.png, espresso.png, flat-white.png, cortado.png

Feat-003 | Coffee Card Grid                                           [done]
-----------------------------
In coffeeType.jsx, render a responsive grid of coffee cards.
Grid layout:
  - CSS Grid, repeat(auto-fill, minmax(14rem, 1fr)), gap 1.5rem
  - Max-width 79.375rem (1270px), centred, padding 2rem 1.5rem

Each card (.coffee-card):
  - Background: var(--white)
  - Border-radius: 0.75rem
  - Overflow: hidden
  - Box-shadow: 0 2px 8px rgba(0,0,0,0.15)
  - Display: flex, flex-direction: column

Card image area (.coffee-card__img-wrap):
  - Position: relative (to anchor the quantity badge)
  - Image fills full width, aspect-ratio 4/3, object-fit cover

Card body (.coffee-card__body):
  - Padding: 1rem
  - Coffee name as H3: colour var(--blue-deep), font-size 1rem, font-weight 700
  - Description as p: colour var(--text-dark), font-size 0.8125rem, margin-top 0.25rem

Card controls (.coffee-card__controls):
  - Row of: minus button, quantity number, plus button
  - Displayed at bottom of card body
  - Minus (−) and Plus (+) buttons:
      width/height 2rem, border-radius 50%, border none
      background var(--red), colour var(--white), font-size 1.25rem
      cursor pointer, font-weight 700
  - Quantity number: min-width 2rem, text-align center, font-size 1rem, colour var(--blue-deep)
  - Minus button disabled (opacity 0.4, pointer-events none) when quantity is 0

Feat-004 | Quantity Badge on Card Image                               [done]
-----------------------------------------
A badge overlaid on the top-right corner of the card image.
Only visible when the item's quantity in basket > 0.
Style (.coffee-card__badge):
  - Position: absolute, top 0.5rem, right 0.5rem
  - Background: var(--gold)
  - Colour: var(--black)
  - Border-radius: 50%
  - Width/height: 1.75rem
  - Display: flex, align-items center, justify-content center
  - Font-size: 0.875rem, font-weight: 700
  - Pointer-events: none (decorative only)
Only render the badge element when quantity > 0 (conditional render in JSX).
