Feat-006 | Previous Orders Modal
----------------------------------
Files:
  hafotty-coffi/src/website/home/home.jsx
  hafotty-coffi/src/website/home/home.scss

In home.jsx:
  - Mock data const MOCK_ORDERS array (5 items) defined above the component
  - useState: const [ordersOpen, setOrdersOpen] = useState(false)
  - Render <button className="home__orders-btn" onClick={() => setOrdersOpen(true)}>
      Previous Orders
    </button>
  - Conditional render: {ordersOpen && <div className="orders-backdrop" onClick={() => setOrdersOpen(false)}>
      <div className="orders-modal" onClick={e => e.stopPropagation()}>
        <button className="orders-modal__close" onClick={() => setOrdersOpen(false)}>×</button>
        <h2>Your Last Orders</h2>
        <ul>
          {MOCK_ORDERS.map(order => <li key={order.id}>...)}</li>)}
        </ul>
      </div>
    </div>}
  - stopPropagation on modal card click prevents backdrop close firing

In home.scss:
  .home__orders-btn: ghost button styles
  .orders-backdrop: position fixed, inset 0, background rgba(0,0,0,0.6), z-index 100,
    display flex, align-items center, justify-content center
  .orders-modal: background var(--white), border-radius 0.75rem, padding 2rem,
    max-width 28rem, width 90%, position relative
  .orders-modal__close: position absolute, top 1rem, right 1rem,
    background none, border none, font-size 1.5rem, cursor pointer

Feat-009 | React Router Wiring
--------------------------------
File:
  hafotty-coffi/src/App.jsx (or wherever the router is configured)

Add imports:
  import Home from './website/home/home'
  import CoffeeType from './website/pages/coffeeType/coffeeType'
  import TeaType from './website/pages/teaType/teaType'

Add routes:
  <Route path="/"       element={<Home />} />
  <Route path="/coffee" element={<CoffeeType />} />
  <Route path="/tea"    element={<TeaType />} />

Ensure BrowserRouter wraps all routes at root level.
If App.jsx does not yet have a router, wrap the <Routes> block in <BrowserRouter>.

Dependency check:
  react-router-dom must be installed: npm install react-router-dom
