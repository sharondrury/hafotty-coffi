Feat-003 | sendOrder Component
Test status: passed

Manual test steps:
  1. Add at least one item to the basket and navigate to /#/basket.
  2. Check a text input labelled "Your name" and a "Send Order" button appear below the list.
  3. Leave the name field empty and click "Send Order".
  4. Check an inline error message appears: "Please enter your name before sending."
  5. Check no email was sent (the button should not have triggered a request).
  6. Start typing in the name field — check the error message disappears.
  7. Enter a name and click "Send Order".
  8. Check the button label changes to "Sending..." and the button is disabled.
  9. (Requires real key) Check the button returns and success or error state appears.
Expected result per step:
  2. Input and button visible below the basket list.
  3. Error message appears, no network request made.
  4. Inline message in red text.
  5. No email in inbox.
  6. Error message disappears as soon as user types.
  7-8. Button shows "Sending..." in disabled state while request is in flight.
Automated tests completed: none.
Automated tests still needed:
  - Unit: empty name prevents send and sets nameError true.
  - Unit: typing resets nameError to false.

Feat-005 | Basket Page — Form + Status States
Test status: passed

Manual test steps (idle → success flow):
  1. Add items to the basket and navigate to /#/basket.
  2. Check item list is visible with quantity controls.
  3. Check "Your name" input and "Send Order" button appear below the list.
  4. Enter your name and click "Send Order".
  5. (Requires real key) After send completes successfully:
     — Check item list disappears.
     — Check green/teal message: "Order sent! We'll get started on that for you."
     — Check gold "Back to Home" button is visible.
  6. Click "Back to Home" — should navigate to /#/.
  7. Check basket is now empty (basket icon shows no badge).

Manual test steps (idle → error flow):
  1. Temporarily set VITE_EMAILJS_PUBLIC_KEY to an invalid value in .env and restart dev server.
  2. Add items, enter name, click "Send Order".
  3. After send fails:
     — Check item list is still visible.
     — Check red error message: "Something went wrong — please check your details and try again."
     — Check "Send Order" form is still visible for retry.
  4. Restore the correct key when done testing.

Manual test steps (empty basket):
  1. Navigate to /#/basket with no items.
  2. Check only the empty state message is shown — no "Send Order" form.

Expected result per flow:
  Success: success message shown, basket cleared, Home button visible.
  Error: error message shown, list and form still present for retry.
  Empty: no form shown.
Automated tests completed: none.
Automated tests still needed:
  - Unit: orderStatus 'success' renders success screen, not item list.
  - Unit: orderStatus 'error' renders error message and keeps form visible.
  - Unit: empty basket renders empty state with no SendOrder component.
  - Unit: useEffect calls clearBasket when orderStatus becomes 'success'.
