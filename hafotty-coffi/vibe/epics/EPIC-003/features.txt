Feat-002 | Tea Card Grid                                              [done]
----------------------------
Render a responsive grid of tea cards — same layout and structure as coffeeType.
Grid: CSS Grid, repeat(auto-fill, minmax(14rem, 1fr)), gap 1.5rem,
  max-width 79.375rem, centred, padding 2rem 1.5rem.

Each .tea-card:
  - Background: var(--white), border-radius 0.75rem, overflow hidden
  - Box-shadow: 0 2px 8px rgba(0,0,0,0.15), display flex flex-direction column
Card image: width 100%, aspect-ratio 4/3, object-fit cover.
Card body: name as H3 (var(--blue-deep)), description as p (var(--text-dark)).
Controls: minus button, quantity number, plus button — same as coffee cards.
  - Minus disabled at qty 0
  - Plus: addToBasket(tea)
  - Minus: updateQuantity(tea.id, qty - 1)

Feat-005 | Milk Selection Section                                     [done]
------------------------------
A section below the tea grid allowing the user to choose their milk preference.
Heading: "Choose your milk" — var(--white), centred.
Three options rendered as toggle buttons:
  - Semi-Skimmed
  - Full Fat
  - Plant-Based
Only one can be selected at a time (single select).
Selected state: background var(--teal), colour var(--black), no border.
Unselected state: background none, border 2px solid var(--teal), colour var(--white).
Clicking a selected option again deselects it (toggle to null).
Milk choice stored in basket context (milkChoice, setMilkChoice) — see Feat-006.
