Feat-006 | Previous Orders Modal
----------------------------------
A "Previous Orders" button placed below the two main CTA buttons.
Style:
  - Small ghost button: no fill, border 1px solid var(--gold), colour var(--gold)
  - Font size: 0.875rem (14px)
  - Padding: 0.5rem 1.25rem
  - Border radius: 0.375rem
  - Margin top: 2rem
  - Hover: background var(--gold), colour var(--black)

On click: opens a modal overlay.
Modal content:
  - Backdrop: rgba(0,0,0,0.6), full screen, click backdrop to close
  - Modal card: background var(--white), border radius 0.75rem, padding 2rem, max-width 28rem
  - Heading: "Your Last Orders" — var(--blue-deep), font-size 1.25rem, font-weight 700
  - Displays a list of up to 5 most recent mock orders (hardcoded data for now — array of objects with: id, drink, size, date)
  - Each order row: drink name left, date right, separated by a light border-bottom
  - If no orders: show "No orders yet — try something!" message
  - Close button (×) top right of modal card
Modal state managed with useState in home.jsx.
Mock data example array defined inline in home.jsx:

    { id: 1, drink: 'Flat White', size: 'Medium', date: '22 Mar 2026' },
