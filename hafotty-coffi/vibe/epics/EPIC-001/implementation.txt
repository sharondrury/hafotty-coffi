Feat-010 | Basket Context (Global State)
------------------------------------------
Files changed:
  hafotty-coffi/src/website/components/basket/basketContext.jsx  (created)
  hafotty-coffi/src/App.jsx  (updated — wrapped with BasketProvider)

What was implemented:
  React Context (BasketContext) with useState holding the basket array.
  BasketProvider exposes: basket, addToBasket, removeFromBasket, updateQuantity, basketCount.
  addToBasket increments quantity if item already exists (matched by id), otherwise appends.
  updateQuantity auto-removes the item when quantity drops to 0.
  basketCount is a derived value (reduce over quantities) — not duplicated in state.
  useBasket() hook exported for clean consumer usage.
  BasketProvider wraps the full app in App.jsx so any component can access basket state.

Engine components considered:
  - websiteContext.jsx: rules reference this path (src/engine/websiteContext/) but the
    engine folder was not created per project decision. Basket context placed in
    src/website/components/basket/ instead, co-located with the basket UI. If a wider
    website context is needed in a future epic, this can be promoted or merged then.
