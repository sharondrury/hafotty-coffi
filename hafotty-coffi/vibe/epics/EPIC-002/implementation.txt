Feat-002 | Basket Context
--------------------------
Not re-implemented. Already exists from EPIC-001.
Location: src/website/components/basket/basketContext.jsx + useBasket.js
Existing API used as-is:
  - basket (array)      → equivalent to items in this spec
  - addToBasket(item)   → equivalent to addItem
  - updateQuantity(id, qty) → used for decrement (handles removal when qty reaches 0)
  - basketCount         → equivalent to totalCount
coffeeType.jsx imports useBasket from '../../components/basket/useBasket'.

Note: spec described this context at src/context/basketContext.jsx but the EPIC-001
decision was to place it in src/website/components/basket/. No duplication created.

Feat-003 | Coffee Card Grid
-----------------------------
Files changed:
  hafotty-coffi/src/website/pages/coffeeType/coffeeType.jsx
  hafotty-coffi/src/website/pages/coffeeType/coffeeType.scss

What was implemented:
  CSS Grid with auto-fill columns (minmax 14rem), gap 1.5rem, max-width 79.375rem.
  Each .coffee-card: white background, border-radius 0.75rem, overflow hidden,
  box-shadow, flex column layout so controls pin to the bottom of the card.

  getQty helper defined in component:
    const getQty = (id) => basket.find(i => i.id === id)?.quantity ?? 0

  Plus button calls addToBasket(coffee) — adds item or increments quantity.
  Minus button calls updateQuantity(coffee.id, qty - 1) — decrements; removes at 0.
  Minus button has disabled attribute when qty === 0 (opacity 0.4, pointer-events none).

Engine components considered:
  - button.jsx: not used — card buttons need tight layout and custom shape (circle).
    Custom .coffee-card__btn class used instead.
