Feat-005 | Coffee & Tea Buttons
---------------------------------
Files changed:
  hafotty-coffi/src/website/pages/home/home.jsx
  hafotty-coffi/src/website/pages/home/home.scss

What was implemented:
  Two <Link> components styled as buttons using BEM modifier classes.
  Coffee button: --red background, --crimson on hover, press-down active state.
  Tea button: --teal background, brightness filter on hover, press-down active state.
  Both use box-shadow 4px 4px 0 var(--black) for the solid shadow effect.
  text-decoration: none applied to remove default Link underline.

Engine components considered:
  - button.jsx: considered but not used — the engine button is likely a <button> element;
    these need to be <Link> components for native router navigation. Styling matches spec
    more precisely with custom classes.

Feat-006 | Previous Orders Modal
----------------------------------
Files changed:
  hafotty-coffi/src/website/pages/home/home.jsx
  hafotty-coffi/src/website/pages/home/home.scss

What was implemented:
  Ghost "Previous Orders" button triggering a useState-controlled overlay.
  Backdrop click closes modal; stopPropagation on modal card prevents accidental close.
  MOCK_ORDERS array (5 items) defined above component.
  Each row shows drink + size on the left, date on the right, with border-bottom separator.
  Empty state message included for future use when orders array is empty.

Engine components considered:
  - modal.jsx / modalContext.jsx: considered — the engine modal was reviewed. For this
    MVP home page the spec calls for a self-contained inline modal without needing a
    global modal context or portal. Inline conditional render keeps the feature isolated
    and easy to upgrade to the engine modal in a future epic when multiple modals exist.
